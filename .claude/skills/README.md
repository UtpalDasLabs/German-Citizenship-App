# Skills for making the channel's videos

- `remotion-best-practices` (and the sub-skills inside it): official Remotion
  skills, from github.com/remotion-dev/skills.
- The twelve `*-mastery` skills, `lottie-bodymovin`, `after-effects`: Disney's
  12 principles of animation, from github.com/dylantarre/animation-principles
  (MIT, see LICENSE-animation-principles).

Use the principles on every kit scene: anticipation before a move, slow in /
slow out (no linear moves), follow-through when a character stops, arcs,
secondary action, squash and stretch on props. See the private repo's KIT.md.
